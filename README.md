# Réussite

Le solitaire classique : monter les quatre familles de l'As au Roi, avec des colonnes en ordre décroissant et des couleurs alternées.

Klondike : sept colonnes, un talon et quatre familles à monter de l'As au Roi. Glisse les cartes ou clique dessus pour les envoyer à la meilleure place. Annuler sans limite.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Réussite → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
